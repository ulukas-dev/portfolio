# Stock Flow — Backend

API REST para gestão de inventário. Foi estruturada como um projecto de portfólio de nível intermédio, com código dividido por responsabilidade, autenticação, validação e transacções de base de dados.

## Tecnologias
- Node.js + Express
- PostgreSQL
- Prisma ORM
- JWT para autenticação
- bcryptjs para hash de palavras-passe
- Zod para validação dos dados
